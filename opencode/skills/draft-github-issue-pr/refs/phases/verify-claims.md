# Phase:VerifyClaims

Re-check the draft, now that its text and motivation are fixed.

## Claims

- Re-check every claim against the final text.
  Remove or hedge anything still `unverified`.
- Run any command you intend to cite (tests, build) now, and paste the real result.
  Never write a result you did not produce.
- The user may also mark a claim `verified` from their own knowledge; that counts.

## Paths and shapes

- Re-check every concrete path, key, method, or config value against the code or docs.
- Remove any detail the code does not support.

## Prose

- One sentence per line.
  Split any line packing multiple sentences.
- Confirm the user's voice and punctuation are intact.
- Confirm the draft opens with the point and cuts filler.

## Conventions

- Every required item in `$repotemplate` and `$repoguidelines` is present, in order, with the same
  headings.
  Advisory items may be omitted.
- The review package has a `##` title heading after the meta `---`, with the body following, and
  its meta matches reality.
- The draft follows the required repo rules: base branch and required checklists.
- Checklist boxes match what was actually done.
