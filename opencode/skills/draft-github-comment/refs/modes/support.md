# Mode: support

Replies to someone else's request: same wish, plus what is still missing for me.

## Shape

1. Same-wish line — one short sentence, no preamble other than the greeting `SKILL.md` permits.
2. Narrow the ask when you only care about part of it.
   > I'd only use the horizontal one
3. Use-case: what you'd build, and why the current surface can't carry it.
4. The concrete gap, named at slot/API/file level.
5. Close with the ask.

Any of these steps may carry a callout marker when the point should not be skimmed past.

## Rules

- Never open with praise, or with a summary of the issue.
- Say what the existing proposal does not cover for you.
  That is the entire value of the comment.
- Name the exact symbol, slot, path, or file when the gap is code-level.
- Do not offer to implement unless the user asked for that.

## Avoid

- "Any update?" nudges.
- Comparisons to other tools that carry no weight for the ask.
- Re-arguing a decision a maintainer already stated in the thread.
