# Mode: clarify

Answers a question in the thread, or clarifies something the user wrote earlier.

## Shape

1. Answer first, one sentence, before any context other than the greeting `SKILL.md` permits.
2. Quote the question or claim being addressed, trimmed to the relevant line.
3. Supporting detail or correction, shortest form.
4. What is still unknown, if anything.

## Rules

- Never restate the question at length.
- Correct only the specific claim, not the whole comment.
- Say "no, and here is what I do instead" plainly when that is the answer.
- Link to the code, doc, or comment carrying the detail instead of re-explaining it.
- Do not re-open settled decisions.
  If the user wants to push back, ask what evidence would change the maintainer's mind.
